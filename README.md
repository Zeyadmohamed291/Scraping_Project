## 🏛️ Executive Summary & Value Proposition

The **Global 50 Corporate Intelligence Platform** bridges the gap between raw web scraping, institutional financial engineering, and executive decision-making. 

Tracking the **50 largest corporations on Earth** representing **$13.94 Trillion in revenue** (~14% of Global GDP) and **16.7+ Million employees**, the application delivers:

1. **Dual-Theme Executive Interface**: Built from the ground up using custom CSS tokens (Light corporate `#F6F8FB` and Dark Bloomberg-style `#0B1120`) with unified two-way synchronization.
2. **Dedicated Business Questions Hub**: An empirical investigation center addressing 10 fundamental macroeconomic inquiries with deep-dive visualizers, dynamic narrative takeaways, and interactive cards.
3. **Advanced Financial Analytics**: Pareto concentration curves, margin dispersion boxplots, capital efficiency 4-quadrant matrices, and workforce scaling OLS regressions.
4. **Enterprise 360 & Comparator**: Comprehensive single-company dossiers and direct head-to-head benchmarking with radar profiles.
5. **Institutional Excel Export**: Multi-sheet `.xlsx` generation with native tables, conditional data bars, auto-filters, freeze panes, and embedded Excel charts.

## 📊 Analytical Depth & Visualizations

The dashboard utilizes Plotly Graph Objects to deliver publication-quality visual models:

1. **Natural Earth Sovereign Choropleth (3D-Shaded)**: ISO Alpha-3 geographic projections illustrating country-level revenue concentration with custom corporate hover templates.
2. **Capital Efficiency 4-Quadrant Matrix**: Scatter plot segmenting the cohort into *Efficiency Champions*, *Scaled Giants*, *Lean Disruptors*, and *Volume Aggregators*.
3. **Pareto Concentration Curve**: Dual-axis Lorenz curve charting cumulative enterprise revenue contribution against equal-distribution baselines.
4. **Profit Margin Dispersion**: Highlighting pricing power, cost-structure resilience, and private vs. public firm disclosures (graceful handling of unlisted entities).
5. **Sector Revenue Allocation Micro-Strip**: Ultra-compact, contrast-adaptive distribution bar embedded in the executive hero header.

## 📁 Professional OpenPyXL Excel Export Engine

Unlike basic CSV dumps, the platform features a financial-grade Excel workbook export system generated via `openpyxl`:

```
global50_all_companies_20260913.xlsx
├── 📄 Cover Sheet     (Corporate title, metadata, generated timestamp, summary KPI cards)
├── 📊 All Data        (Official Excel Table, freeze panes, conditional data bars on Revenue/Profit)
├── 🏢 Benchmarks      (Formatted Industry & Sovereign benchmark aggregation tables)
└── 📈 Charts          (Native openpyxl Bar Charts: Top 10 Revenue & Top 10 Profit)
```

- **Dynamic Filenames**: Automatically reflects applied filters (e.g. `global50_apple_United_States_filtered_20260913.xlsx`).
- **Data Integrity**: Clean currency and percentage number formatting (`$#,##0.0B`, `0.0%`, `#,##0`).

## 🚀 Quick Start & Local Setup

### 1. Prerequisites
Ensure you have Python 3.10 or newer installed:
```bash
python --version
```

### 2. Clone the Repository
```bash
git clone https://github.com/Zeyadmohamed291/Scraping_Project.git
cd Scraping_Project
```

### 3. Set Up a Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Launch the Streamlit Dashboard
```bash
streamlit run streamlit_app.py
```
Your default web browser will launch automatically at `http://localhost:8501`.
